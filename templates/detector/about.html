ℹ️ About This Project

Learn about the methodology, dataset, and technology behind this system.

🎯 Project Objective

The AI-Based Intrusion Detection System (IDS) is a college academic project designed to demonstrate how machine learning algorithms can be applied to network security. The system analyzes network traffic features and classifies connections as Normal or Attack using pre-trained ML models.

📊 Dataset

This project uses the NSL-KDD dataset, which is a refined and improved version of the original KDD Cup 1999 dataset. It is one of the most widely used benchmark datasets in intrusion detection research. The dataset contains 41 network traffic features and covers the following attack categories:

  • DoS (Denial of Service) — Flooding the network to make services unavailable
  • Probe — Scanning the network to gather information
  • R2L (Remote to Local) — Unauthorized access from a remote machine
  • U2R (User to Root) — Unauthorized privilege escalation

🤖 Machine Learning Approach

The system trains and evaluates multiple classification algorithms to identify the most effective model for intrusion detection. Algorithms being considered include:

  • Random Forest Classifier
  • Decision Tree Classifier
  • K-Nearest Neighbors (KNN)
  • Support Vector Machine (SVM)

🛠️ Technology Stack

  • Backend: Python 3.11, Django 4.2
  • Database: SQLite
  • Frontend: HTML5, CSS3, JavaScript
  • ML Libraries: Scikit-learn, Pandas, NumPy
  • Visualization: Matplotlib
  • Model Persistence: Joblib

⚠️ Disclaimer

This project is developed strictly for academic and educational purposes. It uses a publicly available dataset and does not involve any live network monitoring, real cyber attacks, or unauthorized access to any systems. All detection is performed on pre-recorded, anonymized network traffic data.
